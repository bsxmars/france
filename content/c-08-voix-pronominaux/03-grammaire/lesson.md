Местоимённые глаголы во французском значительно разнообразнее русских глаголов на *-ся*. Частица *se* может быть настоящим дополнением («себя», «себе», «друг друга»), а может быть просто частью глагола. От этого зависит главное практическое правило — **согласование причастия** в сложных временах, которое регулярно проверяют на экзаменах C1 и в котором ошибаются даже носители. В этом уроке — глаголы, где *se* сохраняет свою роль: **возвратные** (*réfléchis*) и **взаимные** (*réciproques*).

## 1. Классификация

| Тип | Роль se | Пример |
|---|---|---|
| **réfléchi** возвратный | себя / себе | *Elle **se** regarde dans le miroir.* |
| **réciproque** взаимный | друг друга / друг другу | *Ils **s'**écrivent chaque semaine.* |
| **essentiellement pronominal** собственно местоимённый | нет роли, часть глагола | *Il **s'**est enfui.* |
| **à sens passif** с пассивным значением | нет роли | *Ce plat **se** mange froid.* |

Два последних типа — в уроке 4.

Все местоимённые глаголы в сложных временах спрягаются с ***être***: *je me suis levé*, *nous nous étions parlé*. Но согласование причастия у réfléchis и réciproques подчиняется **правилу *avoir***: смотрят, есть ли перед глаголом **прямое дополнение**.

## 2. Se — прямое или косвенное дополнение?

Мысленно замени *être* на *avoir* и спроси: «кого?» или «кому?».

- *Elle s'est lavée.* → *elle a lavé **qui** ?* — *se* (себя) = **COD** → согласование: *lavée*.
- *Elle s'est lavé **les mains**.* → *elle a lavé **quoi** ?* — *les mains* = COD, а *se* = **COI** (себе) → COD стоит **после** глагола → **без согласования**: *lavé*.
- *Les mains, elle **se les** est lavées.* → COD *les* стоит **перед** глаголом → согласование: *lavées*.

То же у взаимных глаголов:

- *Ils se sont **battus**.* — *ils ont battu l'un l'autre*, *se* = COD → согласование.
- *Ils se sont **serré** la main.* — *se* = COI (друг другу), COD *la main* после глагола → нет согласования.
- *Elles se sont **regardées**.* — *regarder qn* → COD → *regardées*.
- *Elles se sont **souri**.* — *sourire à qn* → COI → *souri* без согласования.

### Глаголы, при которых se всегда COI

Если глагол управляет **косвенным** дополнением с *à*, причастие **никогда** не согласуется:

*se parler, se téléphoner, se sourire, se répondre, se mentir, se nuire, se plaire* (нравиться друг другу), *se déplaire, se succéder, se ressembler, s'écrire, se dire, se demander, se promettre, se rendre compte, se permettre, s'imaginer* (с дополнением), *se donner* (с дополнением).

- *Ils se sont **parlé** pendant des heures.*
- *Les rois se sont **succédé**.*
- *Elles se sont **plu** dès le premier jour.*
- *Elle s'est **permis** de critiquer.* (*permettre à soi*)
- *Ils se sont **téléphoné**.*

### Когда COD стоит перед глаголом

Если прямое дополнение вынесено вперёд — местоимением или относительным *que* — причастие согласуется **с ним**:

- *Les lettres **qu'**ils se sont **écrites**.* (COD *que* = *les lettres*)
- *Quelles promesses se sont-ils **faites** ?*
- *Cette robe, elle **se l'**est **offerte** pour ses trente ans.*

## 3. Взаимность: как её подчеркнуть

Форма множественного числа двусмысленна: *Ils se regardent* — «смотрят на себя» или «друг на друга»? Уточнение — ***l'un l'autre, les uns les autres***, с нужным предлогом: *Ils se méfient **l'un de l'autre***, *Elles se parlent **l'une à l'autre***, *Ils se sont battus **les uns contre les autres***. Наречие ***entre eux*** / ***mutuellement*** тоже снимает двусмысленность.

Взаимный глагол бывает только во **множественном числе** или с *on* = *nous*: *On s'est vus hier* (причастие по смыслу во мн. ч.).

## 4. Повелительное наклонение и инфинитив

- Утверждение: местоимение **после** глагола, через дефис, *te* → ***toi***: *Lave-**toi***, *Dépêchons-**nous***, *Asseyez-**vous***.
- Отрицание: обычный порядок: *Ne **te** lave pas*, *Ne **vous** inquiétez pas*.
- Инфинитив: местоимение **согласуется с подлежащим**: *Je dois **me** lever tôt*, *Nous allons **nous** promener*, *Tu as raison de **t'**en occuper* (не ~~de s'en occuper~~).

> **Уровень C1:** при глаголах *se faire, se laisser, se voir, s'entendre* + инфинитив причастие обычно **не согласуется**: *Elle s'est **fait** opérer*, *Elle s'est **laissé** convaincre* (по реформе 1990 года *laissé* неизменяемо всегда). С *se voir, s'entendre* согласование зависит от того, выполняет ли подлежащее действие инфинитива: *Elle s'est **vue** mourir* (она умирала) — *Elle s'est **vu** refuser l'entrée* (ей отказали).

> **Типичная ошибка русскоговорящих:** ~~Elle s'est lavée les mains~~, ~~Ils se sont parlés~~, ~~Elle s'est coupée le doigt~~. Русская логика «она — значит, женский род» ведёт к лишнему согласованию. Алгоритм: замени *être* на *avoir* и найди COD. Если *se* — COI или COD стоит после глагола, причастие неизменно.

## Проверь себя

```quiz
q: "Elle s'est ___ le genou en tombant."
options: ["blessée", "blessé", "blessés"]
answer: 1
explain: "COD — *le genou* (после глагола), *se* = «себе» (COI) → без согласования: **blessé**."
```

```quiz
q: "Ils se sont ___ sans se reconnaître."
options: ["croisés", "croisé", "croisées"]
answer: 0
explain: "*Croiser qn* — прямое дополнение: *se* = COD «друг друга» → **croisés**."
```

```quiz
q: "Les messages qu'elles se sont ___ étaient très tendres."
options: ["envoyé", "envoyés", "envoyées"]
answer: 1
explain: "COD *que* = *les messages* (м. р. мн. ч.) стоит перед глаголом → **envoyés**; *se* здесь COI."
```
