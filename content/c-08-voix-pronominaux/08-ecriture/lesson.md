**Synthèse** — особый жанр DALF C1: по двум-трём документам нужно написать связный текст, который **сопоставляет** их позиции. Своё мнение высказывать **нельзя**, цитировать целыми фразами — тоже: всё пересказывается своими словами. Здесь грамматика главы работает на перефразирование: пассив позволяет сменить точку зрения (*les plateformes diffusent* → *la diffusion est assurée par les plateformes*), местоимённые глаголы — обобщить (*cela ne se décrète pas*), а выбор *par* / *de* показывает уровень (*une mesure critiquée par les juristes*, *une idée partagée de tous*).

## Устройство синтеза

1. **Заголовок** — обязателен: короткий, отражает проблему (*Fausses informations : sanctionner ou former ?*).
2. **Вступление** (2–3 фразы): общая тема, кто авторы документов и проблематика. Без «В первом документе говорится…».
3. **Основная часть — по темам, а не по документам.** Абзац 1 — в чём авторы **сходятся**, абзац 2 — в чём **расходятся**, абзац 3 — решения, которые они предлагают. Каждый абзац опирается на оба документа.
4. **Вывод не обязателен**; если есть — одна нейтральная фраза, без своего мнения.

Не пиши *je, à mon avis*; не добавляй фактов, которых нет в документах.

## Полезные фразы

| Французский | Зачем |
|---|---|
| Les deux auteurs s'accordent sur… | сходство |
| Leurs positions divergent en revanche sur… | расхождение |
| Selon X, … ; X, au contraire, … | противопоставить |
| X plaide pour que… / mise avant tout sur… | позиция автора |
| … est assuré(e) par… / … est fondé(e) sur… | пассив для перефразирования |
| Cette solution ne se met pas en place du jour au lendemain. | местоимённый пассив |
| X reconnaît toutefois que… | уступка автора, не твоя |

> **Типичная ошибка русскоговорящих:** переносить русское «-ся» механически. ~~Le problème se discute par les experts~~ — при местоимённом пассиве агент не указывают: *le problème **est discuté par** les experts* или *le problème **se discute***. И согласование: *ils se sont **téléphoné**, ils se sont **parlé*** (*se* — косвенное дополнение: *téléphoner à*, *parler à*), но *ils se sont **rencontrés***.

После отправки кнопка «Скопировать для Claude» соберёт запрос на проверку по сетке production écrite DALF C1.
