Три пункта урока: как из прилагательного сделать наречие (*lent → lentement*), как спрягаются глаголы на **-aître** (*connaître, paraître, disparaître*) и глагол **apercevoir** «заметить».

## Наречия на -ment

По-русски наречие образа действия делается из прилагательного суффиксом **-о**: медленный → медленн**о**. Во французском эту роль играет суффикс **-ment**. Главный вопрос — к какой форме прилагательного его присоединять.

### Правило 1: к форме женского рода

Если прилагательное в мужском роде кончается на **согласную**, берём форму женского рода:

| Мужской род | Женский род | Наречие |
|---|---|---|
| lent | lente | lente**ment** — медленно |
| heureux | heureuse | heureuse**ment** — к счастью |
| doux | douce | douce**ment** — тихо, мягко |
| sec | sèche | sèche**ment** — сухо |
| actif | active | active**ment** — активно |
| complet | complète | complète**ment** — полностью |
| léger | légère | légère**ment** — слегка |
| fou | folle | folle**ment** — безумно |

Все изменения женского рода (удвоение согласной, *è*, *-euse*, *-ive*) переходят в наречие.

### Правило 2: к форме мужского рода, если она кончается на гласную

Если прилагательное в мужском роде кончается на **гласную** — звучащую или нет, — **-ment** присоединяется прямо к нему:

- *poli → poli**ment***, *vrai → vrai**ment***, *absolu → absolu**ment***;
- *facile → facile**ment***, *rapide → rapide**ment***, *simple → simple**ment***.

Исключение — **gai → gaiement** (к женскому роду; допустимо и старое написание *gaîment*).

> **Типичная ошибка русскоговорящих:** ~~vraiement~~, ~~poliement~~. У прилагательных на *-i, -ai, -u, -é* лишнего *e* нет: ***vraiment, poliment, absolument***.

### Правило 3: -é- перед -ment

Небольшая группа наречий получает **é** перед суффиксом: *profond → profond**é**ment*, *commode → commod**é**ment*, *précis → précis**é**ment*, *énorme → énorm**é**ment*, *aveugle → aveugl**é**ment*. Их проще запомнить списком.

### Наречия на -amment, -emment

Прилагательные на **-ant** и **-ent** дают наречия на **-amment** и **-emment**: *constant → const**amment***, *élégant → élég**amment***, *récent → réc**emment***, *prudent → prud**emment***, *évident → évid**emment***. Оба окончания звучат одинаково — [amɑ̃]. Исключение: *lent → lentement*.

### Особые случаи

*gentil → **gentiment***, *bref → **brièvement***. И, конечно, *bon → **bien***, *mauvais → **mal***, *meilleur → **mieux*** — не на *-ment*.

### Где ставить

Наречие обычно стоит **после глагола**: *Elle parle **lentement**.* В сложных временах длинные наречия на *-ment* чаще идут после причастия (*Il a répondu **poliment***), а *vraiment, complètement, probablement* — и между вспомогательным глаголом и причастием: *J'ai **complètement** oublié.*

## Глаголы на -aître

Сюда входят **connaître** (знать, быть знакомым), **reconnaître** (узнавать), **paraître** (казаться; появляться; выходить из печати), **apparaître** (появляться, возникать), **disparaître** (исчезать), **reparaître** (снова появляться).

| | connaître |
|---|---|
| je | conn**ais** |
| tu | conn**ais** |
| il / elle / on | conn**aît** |
| nous | conn**aissons** |
| vous | conn**aissez** |
| ils / elles | conn**aissent** |

- Imparfait: *je **connaissais***; futur simple: *je **connaîtrai***; futur dans le passé: *je **connaîtrais***.
- Participe passé: **connu**, **paru**, **apparu**, **disparu**, **reconnu**.
- Passé simple: *il **connut**, il **parut**, il **disparut***.

**Accent circonflexe** ставится над *i* только тогда, когда за ним идёт **t**: *il conna**î**t, je conna**î**trai*, но *je connais, nous connaissons*.

> **Орфография 1990 года** разрешает писать без циркумфлекса: *il connait, connaitre*. В упражнениях курса принимаются оба написания.

В passé composé *connaître, reconnaître, paraître, disparaître* спрягаются с **avoir**: *Le soleil **a disparu** derrière les nuages.* **Apparaître** — с **être**: *Une lumière **est apparue** dans la fenêtre.*

### Connaître или savoir?

Оба значат «знать», но:

- **connaître** + существительное — быть знакомым с человеком, местом, произведением: *Je **connais** bien Lyon. Tu **connais** mon frère ?*
- **savoir** + инфинитив или придаточное — знать факт, уметь: *Je **sais** nager. Je **sais** où il habite.*

**Reconnaître** — «узнать» знакомое: *Je ne t'ai pas **reconnu** avec ta barbe !* А «узнать новость» — это *apprendre*.

## Глагол apercevoir

**Apercevoir** — «заметить, увидеть (часто издали или мельком)». Спрягается как *recevoir*: перед **o** и **u** пишется **ç**, а в 3-м лице мн. ч. основа меняется на *-çoiv-*.

| | apercevoir |
|---|---|
| je | aper**çois** |
| tu | aper**çois** |
| il / elle / on | aper**çoit** |
| nous | aper**cevons** |
| vous | aper**cevez** |
| ils / elles | aper**çoivent** |

- Participe passé: **aperçu**; passé composé: *j'**ai aperçu***.
- Futur simple: *j'**apercevrai***; imparfait: *j'**apercevais***; passé simple: *j'**aperçus***.

*Du balcon, on **aperçoit** la mer.* — С балкона видно море.

**S'apercevoir de qch / que…** — «заметить, осознать»: *Il **s'est aperçu** de son erreur.*

## Проверь себя

```quiz
q: "Наречие от «vrai»:"
options: ["vraiement", "vraiment", "vraiemment"]
answer: 1
explain: "*Vrai* кончается на гласную → *-ment* к мужскому роду: **vraiment**."
```

```quiz
q: "Le bateau ___ à l'horizon. (Корабль исчез за горизонтом.)"
options: ["a disparu", "est disparu", "a disparaît"]
answer: 0
explain: "*Disparaître* в passé composé — с **avoir**, причастие *disparu*: **a disparu**."
```

```quiz
q: "Ils ___ un village au loin. (apercevoir, présent)"
options: ["apercevent", "aperçoivent", "apercoivent"]
answer: 1
explain: "3-е лицо мн. ч.: основа *-çoiv-* → **aperçoivent**. Перед *o* — *ç*."
```
