Первая часть письменного DALF C1 — **synthèse de documents**: по двум-трём текстам (около 1000 слов) пишут связный текст примерно на 220 слов. Это самый «грамматический» жанр экзамена: вся синтеза — **пересказ чужих мыслей**, то есть косвенная речь, вводящие глаголы и косвенные вопросы. Сегодня — укороченный вариант: два документа об отзывах в интернете.

## Правила синтеза

- **Никакого личного мнения**: ни *je pense*, ни оценочных слов от себя. Ты — нейтральный рассказчик.
- **Не копируй фразы** из документов: перефразируй. Цитата допустима одна и короткая.
- **План — по идеям, а не по документам.** Не «документ 1 говорит…, документ 2 говорит…», а «польза отзывов → их пределы → решения», и в каждой части сопоставляются оба документа.
- **Заголовок** обязателен.
- **Объём** — ±10 % от заданного; на экзамене слова считают.

## Устройство

1. **Вступление** (2–3 фразы): тема и проблематика в форме косвенного вопроса — *On peut se demander **dans quelle mesure** …* / ***si** …*
2. **Часть 1** — общая или первая идея с опорой на оба документа.
3. **Часть 2** — противоположная или дополняющая идея.
4. **Вывод** — что объединяет документы (без своего мнения).

## Вводящие глаголы и связки

| Французский | Оттенок |
|---|---|
| X affirme / souligne / rappelle que… | нейтрально, подчёркивает |
| X reconnaît / admet que… | уступка |
| X dénonce / déplore… | критика |
| X s'interroge sur… / se demande si… | вопрос |
| Selon X, … / D'après X, … | источник |
| C'est… que / Ce que soulignent les deux documents, c'est… | общее |
| Tandis que X…, Y… / Si X…, Y en revanche… | сопоставление |

> **Типичная ошибка русскоговорящих:** прямой порядок вопроса внутри косвенного: ~~on se demande est-ce que les avis sont fiables~~ → *on se demande **si** les avis sont fiables*; ~~l'auteur explique qu'est-ce que les clients veulent~~ → *… **ce que** les clients veulent*. И время: в синтезе вводящий глагол ставят в **présent** (*l'association affirme que…*) — так не нужно согласование времён и текст читается легче.
