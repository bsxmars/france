Качественное прилагательное (*adjectif qualificatif*) обозначает признак предмета и согласуется с существительным в роде и числе. Основные формы — *petit / petite, heureux / heureuse* — знакомы с первого года. На уровне C1 важны **редкие** и **книжные** формы, которые встречаются в литературе, прессе и юридических текстах: *une tumeur bénigne, une voix aiguë, une main vengeresse, une solution caduque*. И важно **писать** их правильно: в устной речи многие различия не слышны (*cruel / cruelle*), а на письме ошибка очевидна.

## Общее правило и удвоение согласной

| Мужской род | Женский род | Примеры |
|---|---|---|
| согласная или гласная (кроме *-e*) | **+ e** | *petit — petite, joli — jolie, gris — grise, aimé — aimée* |
| **-e** | без изменений | *large, rapide, sympathique, aimable* |
| **-er, -ier** | **-ère, -ière** | *léger — légère, fier — fière, premier — première* |
| **-f** | **-ve** | *naïf — naïve, neuf — neuve, sportif — sportive, bref — brève* |
| **-eux** | **-euse** | *heureux — heureuse, sérieux — sérieuse* |
| **-el, -eil** | **-elle, -eille** | *cruel — cruelle, formel — formelle, pareil — pareille* |
| **-en, -ien, -on** | **-enne, -ienne, -onne** | *européen — européenne, ancien — ancienne, bon — bonne* |
| **-et** | **-ette** | *muet — muette, coquet — coquette, net — nette* |
| **-al, -in, -ain, -ein, -un** | **+ e** без удвоения | *national — nationale, voisin — voisine, plein — pleine, commun — commune* |

### Исключения, которые нужно знать на C1

- **-et → -ète** (без удвоения, с accent grave): *complet — complète, incomplet, concret — concrète, désuet — désuète, discret — discrète, indiscret, inquiet — inquiète, replet, secret — secrète*.
- **-ot**: обычно *+ e* (*idiot — idiote, dévot — dévote*), но удваивают *t*: *sot — sotte, vieillot — vieillotte, pâlot — pâlotte*.
- **-s**: обычно *+ e* (*gris — grise, français — française*), но удваивают *s*: *bas — basse, gras — grasse, gros — grosse, las — lasse, épais — épaisse, exprès — expresse, métis — métisse*.
- **-x**: *doux — douce, roux — rousse, faux — fausse, jaloux — jalouse; vieux — vieille*.
- **-in**: *bénin — **bénigne**, malin — **maligne*** (злокачественная — *une tumeur maligne*; хитрая — *une fille maligne*; в разговорной речи часто *maline*).
- **-u**: *aigu — **aiguë**, ambigu — **ambiguë**, exigu — **exiguë*** (tréma показывает, что *u* произносится); по реформе 1990 — *aigüe, ambigüe, exigüe*.

## Суффиксы -eur: -euse, -trice, -eure, -eresse

- **-eur → -euse**, если прилагательное связано с причастием настоящего времени: *trompeur (trompant) — trompeuse, rêveur — rêveuse, moqueur — moqueuse, menteur — menteuse, travailleur — travailleuse*.
- **-teur → -trice**: *protecteur — protectrice, créateur — créatrice, consolateur — consolatrice, libérateur — libératrice, provocateur — provocatrice, conservateur — conservatrice, destructeur — destructrice*.
- **-eur → -eure** у прилагательных латинской сравнительной степени: *meilleur — meilleure, supérieur — supérieure, inférieur, antérieur, postérieur, intérieur, extérieur, majeur, mineur, ultérieur*.
- **-eur → -eresse** в книжном и юридическом языке: *vengeur — **vengeresse**, enchanteur — **enchanteresse***: *une plume vengeresse, une voix enchanteresse*.

## Особые формы

Эти формы нужно просто помнить:

| М. р. | Ж. р. | | М. р. | Ж. р. |
|---|---|---|---|---|
| *blanc* | ***blanche*** | | *long* | ***longue*** |
| *franc* | ***franche*** | | *oblong* | ***oblongue*** |
| *sec* | ***sèche*** | | *gentil* | ***gentille*** |
| *frais* | ***fraîche*** (*fraiche* по реформе 1990) | | *nul* | ***nulle*** |
| *public* | ***publique*** | | *favori* | ***favorite*** |
| *grec* | ***grecque*** | | *coi* | ***coite*** (*rester coi* — онеметь) |
| *turc* | ***turque*** | | *caduc* | ***caduque*** (устаревший, недействительный) |

> **Уровень C1: прилагательные одного рода.** Некоторые прилагательные употребляются только с существительными одного рода: *un nez **aquilin*** (орлиный), *un homme **pantois*** (ошеломлённый), *un **preux** chevalier* — только м. р.; *une femme **enceinte***, *rester bouche **bée***, *une porte **cochère*** — только ж. р. *Châtain* (каштановый — о волосах) традиционно не изменяется в роде: *une chevelure châtain* (сегодня допускают и *châtaine*). *Chic* не изменяется в роде: *une robe chic*.

> **Типичная ошибка русскоговорящих.** Мы «слышим» женский род и пишем по звуку: ~~une réponse concrette~~ (по аналогии с *muette*), ~~une décision secrette~~, ~~une voix aigue~~, ~~une affaire publiquée~~. Правило: *-et* удваивает *t* (*muette, coquette*), кроме девяти слов на *-ète*, которые стоит выучить списком. И не путай *public — publique* с *publié* (опубликованный).

## Проверь себя

```quiz
q: "Le médecin l'a rassurée : la tumeur est ___."
options: ["bénine", "bénigne", "bénignne"]
answer: 1
explain: "*Bénin* → ***bénigne*** (как *malin → maligne*). Форма *bénine* — ошибка."
```

```quiz
q: "Elle est restée très ___ sur ses projets."
options: ["discrète", "discrette", "discrêtte"]
answer: 0
explain: "*Discret* входит в группу на *-ète*: ***discrète***, без удвоения *t*."
```

```quiz
q: "Le juge a prononcé une sentence ___."
options: ["vengeuse", "vengeresse", "vengeatrice"]
answer: 1
explain: "Книжное ***vengeresse*** — женский род от *vengeur* (как *enchanteresse*)."
```
