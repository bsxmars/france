Первый французский текст целиком — короткое письмо подруге. В нём только то, что уже пройдено: *être*, глаголы на *-er*, притяжательные (*mon, ma, leur*), профессия без артикля и *ne… pas*. На экзамене DELF A1 такие тексты — письмо, объявление, записка — и вопросы «кто? где? что делает?».

## Как читать

1. **Сначала пробеги глазами весь текст**: кто пишет, кому, о чём. Незнакомые слова пропускай.
2. **Прочитай вопросы** и найди в тексте нужное место: вопросы идут по порядку.
3. **Следи за притяжательными**: *son mari* — «её муж», *leur fille* — «их дочь». От них часто зависит ответ «чей?».
4. **Отрицание** *ne… pas* меняет смысл целиком: *Elle n'est pas étudiante* — «она не студентка».

## Слова из текста

| Слово | Перевод |
|---|---|
| chère / cher | дорогая / дорогой (в обращении) |
| chez | у (кого-то), в доме у |
| le mari | муж |
| l'appartement (м.) | квартира |
| petit / petite | маленький / маленькая |
| aussi | тоже |
| la rue | улица |
| le soir | вечер, вечером |
| la musique | музыка |
| jouer du piano | играть на пианино (*du* = *de* + *le*) |
| chanter | петь |
| beaucoup | много |
| timide | застенчивый |
| bisous | целую (в конце письма) |
