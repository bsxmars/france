Ступень B2 → C1 устроена иначе, чем предыдущие: это не учебник с досье, а **грамматика целиком** — главы справочника Поповой и Казаковой, от существительного до выделения. Многое из неё ты уже знаешь: артикль, местоимения, subjonctif, conditionnel встречались и на B1, и на B2. Вопрос в том, **насколько твёрдо**. Этот тест показывает, какие главы можно пройти быстро, а где базу ещё нужно достраивать, прежде чем браться за тонкости уровня C1.

## Что проверяет тест

Каждый модуль ступени — одна глава (или несколько коротких). Тест задаёт **по три вопроса на модуль**:

| Модуль | Темы |
|---|---|
| c-01 | существительное: женский род, род, множественное число |
| c-02 | артикль: значения, имена собственные, *de* вместо артикля |
| c-03 | прилагательное: формы, согласование, сравнение |
| c-04 | личные местоимения: нейтральное *le*, *soi*, *y* и *en* |
| c-05 | относительные, указательные, притяжательные местоимения |
| c-06 | неопределённые слова, *même*, *tout* |
| c-07 | наречие и отрицание |
| c-08 | переходность, пассив, местоимённые глаголы |
| c-09 | présent и будущие времена |
| c-10 | прошедшие времена индикатива |
| c-11 | согласование времён и императив |
| c-12 | conditionnel и предложения с *si* |
| c-13 | subjonctif |
| c-14 | неличные формы и каузатив |
| c-15 | косвенная речь, косвенный вопрос, выделение |

| | |
|---|---|
| Вопросов | 45 |
| Формат | выбор одного варианта из трёх |
| Время | 25–30 минут |
| Уровень | от B2 до C1 |
| Порядок | по модулям, от первого к пятнадцатому |

Правила те же, что во входном тесте прошлой ступени:

1. **Без словаря, справочника и переводчика.** Тест должен показать твою грамматику, а не умение искать.
2. **Не угадывай.** Не знаешь — пропусти вопрос. Угаданный ответ сделает слабую тему «сильной» на странице «Прогресс».
3. **Не застревай.** Больше минуты на вопрос — переходи к следующему.

После проверки под каждым вопросом появится объяснение по-русски. Прочитай хотя бы те, где ошибся: это краткие формулировки правил, которые подробно разбираются в модулях.

> **Засчитывается любая попытка.** Тест нельзя «не сдать»: он нужен для карты, а не для оценки.

## Как читать результат

Каждый вопрос привязан к своему модулю. После теста открой страницу **«Прогресс»**: у модулей c-01 … c-15 появится результат — сколько из трёх вопросов решено верно. В конце ступени рядом встанет **итоговый тест** (модуль c-16) по тем же темам, на новых и более трудных предложениях.

| Результат по модулю | Что делать |
|---|---|
| 3 из 3 | База держится. Теорию можно читать бегло — по заголовкам, блокам «Уровень C1» и «Типичная ошибка», — но упражнения сделай все: тонкости C1 (литературные времена, регистр soutenu, редкие исключения) в тест почти не вошли. |
| 2 из 3 | Основа есть, но с пробелами. Читай внимательно разделы, где ошибся, и переделай упражнения с ошибками. |
| 0–1 из 3 | **Главная тема для тебя.** Теория целиком, карточки, повтор упражнений через несколько дней. |

Три вопроса на модуль — грубый ориентир: одна случайная ошибка сдвигает результат на треть. Поэтому смотри и на **группы модулей**. Ошибки в c-09, c-10, c-11 и c-15 вместе обычно означают, что не держится система времён и их согласование; ошибки в c-12 и c-13 — что путаются наклонения; ошибки в c-08 и c-14 — что не уложено согласование причастия.

> **Важно:** даже сильные модули не пропускай целиком. Главы опираются друг на друга: согласование причастия проходит через c-08 и c-14, наклонения — через c-12 и c-13, времена — через c-09, c-10, c-11 и c-15. Результат говорит не о том, что выбросить, а о том, **где идти быстрее и где задержаться**.
