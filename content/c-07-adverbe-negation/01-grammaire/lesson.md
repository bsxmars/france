Русское наречие образуется от прилагательного почти механически: *медленный → медленно*, *частый → часто*. Французское *-ment* тоже выглядит простым суффиксом, но к какой форме прилагательного он присоединяется — к мужской, к женской или к особой основе на *-é-*, — решает несколько правил и десяток исключений. На уровне C1 именно эти исключения выдают иностранца в письменной работе: ~~profondement~~, ~~gentilment~~, ~~évidamment~~, ~~briefment~~.

## 1. Основное правило: женский род + -ment

Если прилагательное оканчивается в мужском роде на **согласную**, берём **женский род** и добавляем *-ment*:

| Прилагательное | Женский род | Наречие |
|---|---|---|
| lent | lente | **lentement** |
| heureux | heureuse | **heureusement** |
| doux | douce | **doucement** |
| franc | franche | **franchement** |
| sec | sèche | **sèchement** |
| fou | folle | **follement** |
| frais | fraîche | **fraîchement** (1990: *fraichement*) |
| public | publique | **publiquement** |
| vif | vive | **vivement** |

Прилагательные на немое *-e* уже «женские»: *facile → facilement*, *rapide → rapidement*, *triste → tristement*.

## 2. Мужской род на гласную: -ment без e

Если мужской род оканчивается на **произносимую гласную** (*-é, -i, -u, -ai*), *-ment* присоединяется к **мужской** форме, и немое *e* женского рода не пишется:

- *vrai → **vraiment***, *poli → **poliment***, *absolu → **absolument***, *aisé → **aisément***, *spontané → **spontanément***, *résolu → **résolument***.

Небольшая группа на *-u* сохраняет память о выпавшем *e* в виде циркумфлекса: ***assidûment**, **continûment**, **crûment**, **dûment**, **goulûment***. Реформа 1990 года разрешает писать без него (*assidument*, *continument*), обе формы правильны. Зато ***gaiement*** сохраняет *e*; вариант ***gaîment*** (1990: *gaiment*) встречается реже.

## 3. Особая основа на -ément

У части прилагательных на согласную или немое *e* наречие образуется на **-ément** — это нужно просто запомнить:

| -ément | Значение |
|---|---|
| profondément | глубоко |
| précisément | точно, именно |
| énormément | чрезвычайно много |
| confusément | смутно |
| commodément | удобно |
| aveuglément | слепо, безрассудно |
| intensément | интенсивно |
| immensément | безмерно |
| expressément | нарочно, специально |
| conformément | в соответствии |
| uniformément | единообразно |
| communément | обычно, как правило |
| obscurément | смутно |
| importunément, opportunément | некстати, кстати |

## 4. Отдельные исключения

- *gentil → **gentiment*** (не ~~gentillement~~);
- *bref → **brièvement***, *grave* → *gravement*, но устойчиво ***grièvement blessé*** («тяжело ранен»): *grièvement* употребляется только с ранениями и ожогами — ***gravement** malade*;
- *bon → **bien***, *mauvais → **mal***, *meilleur → **mieux***;
- *traître → **traîtreusement***, *impuni → **impunément***;
- *nul → **nullement*** («ничуть, нисколько» — книжное отрицание, см. урок 4).

Не от всех прилагательных образуется наречие: у *content, charmant, fâché, mobile, tremblant* его нет. Тогда используется оборот: *d'un air content*, *avec charme*, *de façon charmante*, *d'une manière fâchée*.

## 5. Прилагательные на -ant, -ent: -amment, -emment

Прилагательные на ***-ant*** дают ***-amment***, на ***-ent*** — ***-emment***: суффикс *-nt* «сливается» с *-ment*.

| -ant → -amment | -ent → -emment |
|---|---|
| brillant → **brillamment** | évident → **évidemment** |
| courant → **couramment** | prudent → **prudemment** |
| suffisant → **suffisamment** | fréquent → **fréquemment** |
| constant → **constamment** | récent → **récemment** |
| bruyant → **bruyamment** | violent → **violemment** |
| abondant → **abondamment** | patient → **patiemment** |
| méchant → **méchamment** | négligent → **négligemment** |

**Произношение:** оба окончания звучат одинаково — **[amɑ̃]**: *évidemment* [evidamɑ̃], *fréquemment* [frekamɑ̃]. Отсюда главная орфографическая ловушка: на слух не определить, *-amment* или *-emment*. Помогает только прилагательное: *évid**e**nt → évid**e**mment*, *const**a**nt → const**a**mment*.

Исключения, которые выпадают из правила: ***lentement*** (от *lent*), ***présentement*** (от *présent*), ***véhémentement*** (книжн.).

> **Типичная ошибка русскоговорящих:** ~~évidament~~, ~~fréquament~~, ~~constemment~~. По звуку [amɑ̃] пишут то одну *m*, то не ту гласную. Правило без исключений: в *-amment* и *-emment* всегда **две m**, а гласная повторяет гласную прилагательного (*-ant* → *a*, *-ent* → *e*).

## 6. Прилагательное в роли наречия

В ряде устойчивых сочетаний наречием служит **неизменяемое прилагательное** мужского рода: *parler **bas** / **fort***, *coûter **cher***, *sentir **bon***, *voir **clair***, *travailler **dur***, *chanter **faux***, *s'arrêter **net***, *refuser **net***. Здесь прилагательное не согласуется: *Ces robes coûtent **cher*** (не ~~chères~~). Наречие на *-ment* в этих сочетаниях либо невозможно, либо меняет смысл: *refuser net* «наотрез отказаться» — *nettement* «явно, отчётливо».

> **Уровень C1:** в письменной речи цепочка из трёх-четырёх наречий на *-ment* утяжеляет фразу (*Il a rapidement et efficacement, mais malheureusement assez maladroitement…*). Стилисты советуют заменять часть из них оборотами *avec* + существительное (*avec efficacité*), *de manière / de façon* + прилагательное или прилагательным в роли наречия.

## Проверь себя

```quiz
q: "Il a répondu ___ à toutes les questions du jury."
options: ["brillament", "brillamment", "brillemment"]
answer: 1
explain: "*Brillant* оканчивается на *-ant* → **brillamment**: две *m*, гласная *a* как в прилагательном."
```

```quiz
q: "Son grand-père est ___ malade depuis l'hiver."
options: ["grièvement", "gravement", "gravemment"]
answer: 1
explain: "*Grièvement* сочетается только с ранениями и ожогами (*grièvement blessé, brûlé*). С болезнью — **gravement malade**. *Gravemment* не существует: *grave* оканчивается на немое *e* → *gravement*."
```

```quiz
q: "Какое наречие образовано неправильно?"
options: ["profondément", "gentiment", "poliement"]
answer: 2
explain: "*Poli* оканчивается на гласную → *-ment* присоединяется к мужскому роду без *e*: **poliment**."
```
