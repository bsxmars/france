Камилла пишет подруге из деревни, где гостит у бабушки с дедушкой. В письме — вся грамматика урока: *y* («туда, там») и *en* («оттуда») вместо уже названного места, глагол *faire* во всех лицах, вопросы *quand ?* и *comment ?* с инверсией. На DELF A1 в личном письме спрашивают: где автор, с кем, что делает утром, днём и вечером, о чём спрашивает адресата.

## Как читать письмо

1. **Сначала — кто, где, с кем**: первые две строки письма.
2. **Ищи слова времени — они делят текст на части**: *le matin, l'après-midi, le soir*. Вопросы часто идут по этим частям.
3. **Y и en отсылают назад**: прочитав *nous y allons*, найди место, названное раньше (*au village*). *Nous en revenons* — возвращаемся **оттуда** же.
4. **Вопросы в конце письма** обращены к адресату — на DELF о них тоже спрашивают: *Quand pars-tu… ?*

## Слова из текста

| Слово | Перевод |
|---|---|
| la campagne | деревня, сельская местность |
| les grands-parents | бабушка и дедушка |
| le grand-père / la grand-mère | дедушка / бабушка |
| faire une promenade | гулять, прогуливаться |
| le village | деревня, посёлок |
| à pied | пешком |
| le mercredi | по средам |
| à midi | в полдень |
| les légumes (м.) | овощи |
| la rivière | река |
| jouer aux cartes | играть в карты |
| faire des progrès | делать успехи |
| la mer | море |
| en août | в августе |
