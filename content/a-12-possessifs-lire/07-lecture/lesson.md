Объявление городской библиотеки о клубе чтения. В нём вся грамматика урока: притяжательные «наш, ваш, их» (*notre, vos, leurs*), указательные *ce, cet, cette, ces* и глаголы *lire* и *écrire* во всех лицах. На DELF A1 объявление — один из самых частых документов: из него надо достать **что, когда, где, для кого и сколько стоит**.

## Как читать объявление

1. **Заголовок и первая строка** говорят, о чём речь и для кого: *Vous aimez lire ? Notre club est pour vous !*
2. **Ищи «опорные точки»**: дни недели (*le jeudi*), время (*à six heures*), место (*au premier étage*), цену (*gratuit*), контакт (*écrivez à…*).
3. **Le + день недели** значит «каждый такой день»: *le jeudi* — «по четвергам», *le samedi matin* — «по субботам утром».
4. **Следи, чей предмет**: *notre club* — клуб библиотеки (пишут «мы»), *vos textes* — тексты читателей, *leurs parents* — родители детей.

## Слова из текста

| Слово | Перевод |
|---|---|
| le club de lecture | клуб чтения |
| la bibliothèque | библиотека |
| le jeudi | по четвергам |
| ensemble | вместе |
| préféré / préférée | любимый / любимая |
| ce mois-ci | в этом месяце |
| court / courte | короткий / короткая |
| apporter | приносить |
| le / la bibliothécaire | библиотекарь |
| le poème | стихотворение |
| le commentaire | замечание, отзыв |
| la salle | зал, комната |
| au premier étage | на втором этаже (во Франции этажи считают от *rez-de-chaussée*) |
| à côté de | рядом с |
| gratuit / gratuite | бесплатный / бесплатная |
