Заметка из местной газеты: после двух лет ремонта открылся старый крытый рынок. Газетный стиль любит **страдательный залог**: важно, *что* сделано, а не *кто* делал (*le marché a été rouvert, les vitraux ont été nettoyés, les travaux ont été financés par la ville*). А рассказ о продуктах держится на **частичном артикле**: *de la viande, du poisson, du fromage* — и *pas de, jamais de* после отрицания. Ещё в тексте трудные формы множественного числа (*vitraux, travaux, bijoux, étals*) и глаголы *ouvrir, offrir, devoir*.

На DELF A2 газетная заметка — частый документ: вопросы о датах, цифрах, кто что сделал и что можно посетителям.

## Как читать

1. **Заголовок и подзаголовок** (*chapeau*) — главная новость в двух строках. Прочитай их первыми.
2. **В пассиве ищи, кто действует, после *par***: *les portes ont été ouvertes **par** la maire* — открыла мэр. Если *par* нет, деятель не важен или неизвестен.
3. **Частичный артикль = «немного, сколько-то»**: *du fromage* — «сыр (какое-то количество)». После отрицания — *de*: *je ne prends jamais **de** plats préparés*.
4. **Последний абзац заметки — практическая информация**: часы, дни, правила. Вопросы о ней — почти всегда.

## Слова из текста

| Слово | Перевод |
|---|---|
| le marché couvert | крытый рынок |
| rouvrir (il a été rouvert) | снова открыть (был снова открыт) |
| les travaux (м. мн.) | ремонт, строительные работы |
| le toit / le mur | крыша / стена |
| en mauvais état | в плохом состоянии |
| financer | финансировать |
| sauver | спасти |
| le vitrail, les vitraux | витраж, витражи |
| un étal, des étals | прилавок, прилавки |
| un marchand | торговец |
| le miel | мёд |
| un bijou, des bijoux | украшение, украшения |
| un plat préparé | готовое блюдо |
| goûter | пробовать |
