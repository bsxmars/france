Первая французская сказка целиком. Сказки, легенды, романы пишут в **passé simple**: им рассказывают события (*il appela, ils partirent, il vit*), а фон и описание — в imparfait (*Pierre était grand et fort*). Вторая тема урока — сравнение действий: *plus vite, moins vite, mieux, le plus vite possible*.

На DELF A2 сказок не дают, но passé simple встречается в любом художественном тексте, и его надо узнавать с первого взгляда. В этом тексте сравнение — ключ к сюжету: кто быстрее, а кто лучше.

## Как читать

1. **Сначала узнай формы passé simple** и вспомни инфинитив: окончания *-a, -it, -ut, -èrent, -irent*: *il tomba* ← *tomber*, *il s'assit* ← *s'asseoir*, *il vit* ← *voir*, *il sourit* ← *sourire*.
2. **Отдели события от фона**: passé simple двигает сюжет (что случилось потом?), imparfait описывает героев и обстановку.
3. **Следи за сравнением**: *Pierre travaillait **plus vite**, Jean travaillait **mieux*** — два разных качества; на этом построен конец сказки.
4. **Вопросы идут по порядку текста**, последний — о смысле всей истории.

## Слова из текста

| Слово | Перевод |
|---|---|
| il était une fois | жил-был, однажды (начало сказки) |
| le meunier / le moulin | мельник / мельница |
| fort / forte | сильный / сильная |
| tomber malade | заболеть |
| le blé | пшеница, зерно |
| rapporter | принести (обратно) |
| l'aube (ж.) | рассвет |
| lourd / lourde | тяжёлый / тяжёлая |
| monter | подниматься (о дороге — идти в гору) |
| s'endormir | заснуть |
| réveiller | будить |
| sourire (il sourit) | улыбаться (он улыбнулся) |
| à tous les deux | обоим |
