Запись в блоге о поездке в Марсель — первый связный рассказ о прошлом. Весь текст в *passé composé*: с *avoir* (*nous avons vu, Julien a pris*) и с *être* (*nous sommes partis, nous sommes arrivés*), с отрицанием, вопросом и наречиями на своём месте (*nous avons déjà réservé, il a beaucoup plu*). Попутно — множественное число на *-aux, -eaux* (*journaux, bateaux, tableaux*) и глагол *connaître*.

## Стратегия DELF A2

1. **Рассказ о прошлом идёт по хронологии**: найди слова времени — *vendredi soir, samedi matin, à midi, l'après-midi, dimanche*. Вопросы следуют за ними.
2. **Действие и участник**: в *passé composé* легко понять, **кто** сделал — по подлежащему и по согласованию: *nous sommes allé**s***, *elle est né**e***.
3. **Отрицание** обнимает только вспомогательный глагол: *je **n'**ai **pas** aimé* — «мне не понравилось». Не пропусти его: от него зависит ответ.
4. **Наречия** *déjà, beaucoup, bien* стоят между вспомогательным глаголом и причастием: ищи их там.

## Слова из текста

| Слово | Перевод |
|---|---|
| le mois dernier | в прошлом месяце |
| il a plu (pleuvoir) | шёл дождь |
| monter / descendre | подняться / спуститься |
| de là-haut | оттуда, сверху |
| la mer | море |
| un bateau, des bateaux | корабль, лодка |
| un journal, des journaux | газета |
| la bouillabaisse | марсельская рыбная похлёбка |
| un bijou, des bijoux | украшение |
| retrouver qn | встретиться с кем-то (условленно) |
| par cœur | наизусть |
| une plage | пляж |
| réserver | забронировать |
