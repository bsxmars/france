**Passé composé** — главное прошедшее время разговорной речи, писем и газет. Им рассказывают, **что произошло**: *Hier, j'**ai vu** Marc. Nous **sommes allés** au cinéma.* В русском одно прошедшее время, а вид (сделал / делал) передаёт глагол. Во французском прошедших времён несколько, и passé composé переводится и совершенным, и несовершенным видом: *J'**ai lu** ce livre* — «я прочитал эту книгу» и «я читал эту книгу». Главное — действие **закончено**.

Это **сложное** время: оно состоит из двух слов, и в каждом можно ошибиться.

## Образование: вспомогательный глагол + причастие

**avoir** или **être** в настоящем времени + **participe passé** (причастие прошедшего времени) смыслового глагола.

| | parler (avoir) | arriver (être) |
|---|---|---|
| je | **ai** parlé | **suis** arrivé(e) |
| tu | **as** parlé | **es** arrivé(e) |
| il / elle | **a** parlé | **est** arrivé / arrivé**e** |
| nous | **avons** parlé | **sommes** arrivé(e)s |
| vous | **avez** parlé | **êtes** arrivé(e)(s) |
| ils / elles | **ont** parlé | **sont** arrivés / arrivé**es** |

### Participe passé

- **I группа** (-er) → **-é**: *parler → parlé, manger → mangé, acheter → acheté*.
- **II группа** (-ir, *nous finissons*) → **-i**: *finir → fini, choisir → choisi*.
- **III группа** — причастия надо запоминать. Самые нужные:

| -u | -i / -is / -it | особые |
|---|---|---|
| voir → **vu** | partir → **parti** | faire → **fait** |
| lire → **lu** | sortir → **sorti** | être → **été** |
| savoir → **su** | dormir → **dormi** | avoir → **eu** [y] |
| pouvoir → **pu** | suivre → **suivi** | naître → **né** |
| vouloir → **voulu** | prendre → **pris** | mourir → **mort** |
| devoir → **dû** | mettre → **mis** | vivre → **vécu** |
| connaître → **connu** | dire → **dit** | aller → **allé** |
| venir → **venu** | écrire → **écrit** | |
| répondre → **répondu** | traduire → **traduit** | |
| attendre → **attendu** | | |

Семьи глаголов образуют причастие одинаково: *prendre → pris, comprendre → compris, apprendre → appris; venir → venu, devenir → devenu, revenir → revenu*.

## Avoir или être?

С **avoir** спрягается подавляющее большинство глаголов: все переходные (*j'ai acheté du pain*), большинство непереходных (*il a dormi, nous avons marché*) и сами *avoir* и *être*: *j'**ai eu** de la chance, il **a été** malade*.

С **être** — небольшой список непереходных глаголов движения и изменения состояния. Его надо выучить:

| туда — обратно | |
|---|---|
| aller — venir | идти — приходить |
| arriver — partir | прибывать — уезжать |
| entrer — sortir | входить — выходить |
| monter — descendre | подниматься — спускаться |
| naître — mourir | родиться — умереть |
| rester — tomber | оставаться — падать |
| rentrer, revenir, devenir | возвращаться, возвращаться, становиться |

> **Типичная ошибка русскоговорящих:** ~~j'ai allé~~, ~~il a venu~~. В русском вспомогательного глагола нет, и рука пишет самый частый — *avoir*. Глаголы из списка — только с *être*: *je **suis allé**, il **est venu**, elle **est restée***.

## Согласование с подлежащим (при être)

Причастие при **être** ведёт себя как прилагательное: согласуется с подлежащим в роде и числе.

- *Paul **est arrivé**. Léa **est arrivée**.*
- *Mes frères **sont partis**. Mes sœurs **sont parties**.*
- *Nous (Léa et Anne) **sommes rentrées** tard.*
- Вежливое *vous* к одному человеку — без *-s*: *Madame, vous **êtes arrivée** quand ?*

Если в группе есть хотя бы один мужчина — мужской род: *Paul et Léa **sont venus***.

При **avoir** причастие с подлежащим **не согласуется**: *Léa **a mangé**, elles **ont parlé**.* (Особый случай согласования при *avoir* — в уроке 22.)

## Отрицание и вопрос

Изменяется **вспомогательный глагол**, причастие стоит в стороне.

- Отрицание: ***ne*** + avoir/être + ***pas*** + причастие: *Je **n'ai pas** compris. Elle **n'est pas** venue.*
- Вопрос с инверсией: подлежащее — после вспомогательного глагола: ***As-tu** fini ? **Est-elle** partie ? **A-t-il** répondu ?* (*-t-* между двумя гласными, как в настоящем времени).
- Разговорный вопрос: *Est-ce que vous avez compris ? Vous avez compris ?*
- Вопрос с подлежащим-существительным: *Paul **a-t-il** téléphoné ?*

### Местоимения-дополнения

*Le, la, les, lui, leur, me, te…* стоят **перед вспомогательным глаголом**:

- *Je **l'ai** vu hier. Il **lui a** téléphoné.*
- *Elle **ne m'a pas** répondu.* — *ne* перед местоимением.
- ***L'as-tu** lu ?*

## Место наречий

В сложных временах короткие частотные наречия ставятся **между вспомогательным глаголом и причастием**: **bien, mal, beaucoup, peu, assez, trop, déjà, encore, toujours, souvent, vite**.

- *Tu **as bien** travaillé. Nous **avons beaucoup** marché.*
- *Il **a déjà** fini. — Il **n'a pas encore** fini.*

Наречия **времени и места** (*hier, aujourd'hui, demain, tôt, tard, ici, là-bas, partout*) и большинство длинных наречий на *-ment* стоят **после причастия** (или в начале фразы): *Elle est rentrée **tard**. Je l'ai rencontré **ici**. Il a répondu **calmement**. **Hier**, nous sommes allés au musée.*

Если *beaucoup, peu, assez, trop, encore* относятся не к глаголу, а к существительному, они стоят **перед ним**, после причастия: *Il a fait **beaucoup de** fautes. J'ai lu **encore deux** pages.*

> **Произношение.** В passé composé связывание делается в *il est‿allé, ils ont‿acheté, je ne suis pas‿allé*, но **не** делается в *tu as | acheté* и в вопросе *sont-ils | arrivés ?*

## Проверь себя

```quiz
q: "Hier, ma sœur ___ au théâtre."
options: ["a allé", "est allé", "est allée"]
answer: 2
explain: "*aller* — с **être**, причастие согласуется с подлежащим *ma sœur* (ж. р.): **est allée**."
```

```quiz
q: "Где поставить «déjà»? — Nous avons fini l'exercice."
options: ["Nous avons fini déjà l'exercice.", "Nous avons déjà fini l'exercice.", "Nous déjà avons fini l'exercice."]
answer: 1
explain: "Короткое наречие *déjà* — между вспомогательным глаголом и причастием: *Nous avons **déjà** fini.*"
```

```quiz
q: "«Я его не видел»."
options: ["Je ne l'ai pas vu.", "Je n'ai pas le vu.", "Je ne ai pas l'vu."]
answer: 0
explain: "Местоимение — перед вспомогательным глаголом, *ne* — перед местоимением, *pas* — после *ai*: **Je ne l'ai pas vu**."
```
