# Francais

Личный курс французского в две ступени по 45–60 минут в день: грамматика, чтение, аудирование и письмо. Приложение — Vue 3 + дизайн-система [Aura](https://github.com/ilomee/aura), PWA с интервальным повторением карточек; работает на GitHub Pages и без сети.

| Ступень | Модули | Структура по учебнику | Экзамен-ориентир |
|---|---|---|---|
| A1 → B1 | `a-01`–`a-29` + 3 повторения | Попова, Казакова, Ковальчук «Французский язык», I курс | DELF B1 |
| B1 → B2 | по 8 досье | Cosmopolite 4 | DELF B2 |
| B2 → C1 | по главам | Попова, Казакова «Грамматика французского языка. Практический курс» | DALF C1 |

Из учебников взяты структура, порядок тем и типы упражнений; упражнения и тексты в курсе свои, а в конце каждого урока — ссылки на разделы и страницы книги («Учебник»). Сами книги в курс не входят.

## Запуск

```bash
npm install
npm run dev                  # http://localhost:5173/francais/
```

Курс — статическое приложение на Vue 3 и [Aura](https://github.com/ilomee/aura) (`@ilomee/aura-vue`), без сервера: контент собирается в JSON при сборке, ответы проверяются в браузере. Прогресс хранится в IndexedDB этого браузера (или установленного приложения); на странице «Прогресс» его можно сохранить в файл и загрузить на другом устройстве.

## На телефоне

Сайт — PWA: в Safari «Поделиться → На экран „Домой“», в Chrome «Установить приложение». После первого запуска весь курс работает без сети: уроки, упражнения и карточки лежат в кеше, записи для аудирования кешируются, когда их послушаешь. Новая версия курса скачивается в фоне, и приложение предлагает перезагрузиться.

Тема по умолчанию светлая; кнопка ◐ в шапке переключает на тёмную и запоминает выбор.

Пока поле ответа в фокусе, над клавиатурой есть строка французских букв (é è ê à ç œ « » …, ⇧ — заглавные).

## Сайт на GitHub Pages

1. Создай **публичный** репозиторий на GitHub (Pages бесплатен только для публичных) и запушь проект.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Каждый пуш в `main`/`master` запускает `.github/workflows/pages.yml`: тесты → `validate` → сборка → публикация на `https://<user>.github.io/<repo>/`.

Локально, как на Pages:

```bash
npm run build -- --base=/francais/
npm run preview              # http://localhost:4173/francais/
```

Pages не умеет отдавать одну страницу на все адреса, поэтому сборка кладёт рядом с `index.html` его копию `404.html`: прямая ссылка на урок открывает приложение, а роутер показывает нужную страницу.

## Как заниматься

Начни с **модуля 0** — входного теста. Страница «Прогресс» покажет слабые темы. Дальше по модулям по порядку: один модуль — одна неделя.

| День | Что делать |
|---|---|
| Пн–Ср | урок грамматики: теория, затем 2–3 упражнения. Урок засчитывается, если в каждом упражнении правильно от 80 %. Акценты проверяются строго, но ошибка «только в акцентах» помечается отдельно |
| Чт | чтение: текст уровня B2 и вопросы в формате DELF B2 |
| Пт | письмо: essai, lettre formelle, article, contribution à un forum — 250–300 слов |
| Сб | аудирование: диктант по записям носителей (Tatoeba, CC BY-SA) и вопросы к записи |
| Каждый день | 10 минут карточек во вкладке «Повторение» |

В конце ступени — итоговый тест в формате DELF B2 (модуль 16); его результаты по темам встанут рядом с входным тестом.

### Письмо и Claude

1. **Самопроверка.** После текста нажми «Готово — проверить себя», пройди чек-лист и сохрани работу. Откроется образец ответа.
2. **Разбор с Claude.** Кнопка «Скопировать для Claude» кладёт в буфер запрос: задание, текст и что проверить — исправления, ошибки с объяснением по-русски, оценка по сетке production écrite DELF B2 / DALF C1. На телефоне есть «Поделиться…» — сразу в приложение Claude.
3. **Копия текста.** «Скачать .md» сохраняет текст с заданием и самопроверкой одним файлом.

### Аудирование

- `dictation` — короткие фразы с записью носителя; набираешь, что слышишь. Записи только под открытыми лицензиями (CC0, CC BY, CC BY-SA, общественное достояние), автор и лицензия — под плеером.
- `listening` — запись и вопросы. Записи под копирайтом (RFI, TV5Monde, образцы DELF) не копируются: кнопка открывает их на сайте источника, вопросы и краткое содержание — наши.

## Устройство

```
build/content.ts      загрузка и проверка курса: модули, уроки, упражнения, карточки, аудио (YAML + Markdown)
build/markdown.ts     Markdown → HTML с классами Aura, блоки ```quiz
build/compile.ts      индекс курса + по чанку на урок + карточки
build/course-plugin.ts  Vite-плагин: virtual:course, аудио, перезагрузка при правке контента
build/validate.ts     npm run validate
src/course/           логика без Vue: проверка ответов (акценты строго + подсказка), SM-2,
                      уровни, карточки к повторению, статистика, запрос для Claude
src/stores/           прогресс в IndexedDB (Pinia), тема и ступень в localStorage
src/pages/, src/components/  страницы и компоненты на @ilomee/aura-vue
e2e/                  Playwright: урок целиком, черновики, офлайн, перенос прогресса (телефон и десктоп)
scripts/tatoeba.py    пул французских фраз с открытым аудио и русским переводом
content/              курс
```

## Автору контента

Формат описан в [CONTENT.md](CONTENT.md).

```bash
npm run dev                                 # курс перечитывается с диска на каждое сохранение
npm run validate                            # проверить весь контент
npm test                                    # юнит- и компонентные тесты
npm run build && npm run e2e                # сборка и сквозные тесты в браузере
python3 scripts/tatoeba.py pool             # собрать scripts/pool.tsv
python3 scripts/tatoeba.py fetch 14314      # скачать запись и получить пункт диктанта
```
